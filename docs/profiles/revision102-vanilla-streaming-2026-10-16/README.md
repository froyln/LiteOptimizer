# Vanilla server chunk streaming — 2026-10-16

The exact revision-102 release artifact (SHA-256 `7209ca68471ce6944fae4cb179c2d75bd87e12e007150c5fa8ffba5711943abe`) connected to the unmodified Mojang 1.12.2 server. Revision 104 is the same 729-entry archive except for the manifest revision field, so this runtime test covers its code payload. The server jar hash and current build artifact hash are in [`artifacts.sha256`](artifacts.sha256).

The repeat test used a saved Overworld/Survival baseline at `(1202.5, 4, 762.999)`, F3 chunk `(75, 47)`. The player then sprinted forward for 60 seconds using the instance's configured left-Shift binding. The client reached `(1202.5, 4, 1022.026)`, F3 chunk `(75, 63)`, and rendered the newly streamed terrain. The server-saved player NBT confirms both endpoints, Overworld dimension, Survival mode, and grounded state; the server movement objective recorded 26,396 cm. No RCON movement or correction occurred during the interval. The server recorded no movement warning after the baseline reset. See [`stream-start.png`](stream-start.png), [`stream-end.png`](stream-end.png), [`start-server-state.json`](start-server-state.json), [`end-server-state.json`](end-server-state.json), and [`rcon-results.txt`](rcon-results.txt).

Those events predate the saved test baseline and are retained in [`server.log`](server.log); they are not counted as part of the streaming result.
